# BBP 斜率四：偶数二进伸缩与相邻阶传递

本节只讨论 [原生接力报告](SPARSE-EXCEPTION-RELAY-RESULTS.zh.md) 中定义的
\(Y(n)=Y_{n,4n}\)。使用已建立的 12 项差式和
[共同基与进位报告](MIXED-RANK-CARRY-RESULTS.zh.md) 的有限分部求和恒等式。
本轮沿已有 BBP 对象推进，证明的关键是精确合并十二项有限差。
它补充了[旧移位定理的覆盖窗口](SPARSE-COVERAGE-OBSTRUCTION.zh.md)。
下文是后续推导与复算记录，不是新一轮 Yohaku 原生任务回执。

## 1. 命题与范围

写正整数 \(n=A2^u\)，其中 \(A\) 为正奇数、\(u=v_2(n)\)。定义
\[
 C_A=\max_{0\le k\le(A-1)/2}v_2\binom{A+k}{k},\qquad
 \Gamma_A=v_2\binom{3A}{A}
          =2s_2(A)-s_2(3A),
\]
其中 \(s_2(m)\) 是非负整数 \(m\) 的二进制数字和。
当 \(A\) 为奇数时，\(\Gamma_A\) 与旧增长种子记号
\(\gamma_A=v_2\binom{(3A-1)/2}{(A-1)/2}\) 相同。

**相邻偶数判据。** 若
\[
 \boxed{u\ge\max\{2,\ C_A-\Gamma_A-3\},}
 \tag{A}
\]
则
\[
 \boxed{v_2(Y(n))=-\Gamma_A,\qquad v_2(Q_{n,4n})=4n+\Gamma_A.}
 \tag{B}
\]
\(A\) 可以随 \(u\) 变化；每个点单独检验 (A) 即可。
这是充分条件，尚未证明 (B) 对全部 \(4\mid n\) 成立。

特别地，\(A=3\) 时 \(C_3=\Gamma_3=2\)，因此
\[
 \boxed{v_2(Y(3\cdot2^u))=-2\quad(u\ge2).}
\]
这族的最高两位为二进制 `11`，全部位于旧正种子移位定理的覆盖窗口之外。
其既约分母满足 \(v_2(Q_{n,4n})=4n+2\)。另取 \(A=1\)，得到
\(v_2(Y(2^u))=0\)、\(v_2(Q)=4\cdot2^u\)（\(u\ge2\)）。
对任意固定正奇数 \(A\)，(A) 最终总会成立。因此这个结果允许任意固定的
高位二进制字，只要求末尾附加足够多的零；当 \(A\) 变化时仍须逐点检查 (A)。

## 2. 先证明一个不涉及种子的局部事实

令
\[
 H_n=\frac{(8n)!(4n)!}{(12n)!},\qquad
 \Delta_n=Y(n)-16Y(n-1).
\]
对每个 \(4\mid n\)，有
\[
 \boxed{\Delta_n/H_n\in\mathbb Z_2^{\times}.}
 \tag{C}
\]
而 \(v_2(H_n)=-\Gamma_A\)，所以 (C) 给出
\(v_2(\Delta_n)=-\Gamma_A\)。

把旧 12 项差式的下标换成 \(b=j-3\)，得到
\[
 \frac{\Delta_n}{H_n}
 =\sum_{b=-3}^{8} R_b D_b,
\]
其中
\[
 R_b=\frac{(4n+b)!}{(4n)!}\frac{(12n)!}{(12n+b+1)!},
\]
\[
 D_b=16a_{4n+b}-\sum_{\ell=0}^{b-1}
             (-1)^\ell\binom8\ell a_{4n+b-\ell}.
\]
\(b\le0\) 时内和为空。对于 \(b\ge0\)，
\[
 R_b=\frac{\prod_{i=1}^{b}(4n+i)}
           {\prod_{i=1}^{b+1}(12n+i)}.
\]
因为 \(u\ge2\)，而这些偏移不超过 9，
\[
 v_2(R_b)=-v_2(b+1)\quad(0\le b\le8).
 \tag{D}
\]
三个负偏移分别为
\[
 R_{-3}=\frac{3(12n-1)}{(4n-1)(4n-2)},\quad
 R_{-2}=\frac3{4n-1},\quad R_{-1}=\frac1{4n},
\]
赋值分别为 \(-1,0,-u-2\)。

令 \(P_m\) 是 Pell 数，\(P_0=0,P_1=1,P_{m+1}=2P_m+P_{m-1}\)，
并写 \(x=P_{2n},y=P_{2n+1}\)。有
\[
 v_2(x)=u+1\ge3,\qquad y\text{ 为奇数}.
\]
这里 \(v_2(P_m)=v_2(m)\) 可直接由 Pell 数的奇偶递推和
\(P_{2m}=2P_m(P_{m+1}-P_m)\) 得出：括号内始终为奇数。
利用既有核系数公式
\(a_{2m-1}=P_m^2,a_{2m}=-P_mP_{m+1}\)，将有限系数展开为

| \(b\) | \(D_b\) |
| ---: | --- |
| \(-3\) | \(16P_{2n-1}^2\) |
| \(-2\) | \(-16P_{2n-1}x\) |
| \(-1\) | \(16x^2\) |
| \(0\) | \(-16xy\) |
| \(1\) | \(15y^2\) |
| \(2\) | \(-15xy-22y^2\) |
| \(3\) | \(15x^2+52xy+16y^2\) |
| \(4\) | \(-22x^2-75xy-6y^2\) |
| \(5\) | \(16x^2+60xy+y^2\) |
| \(6\) | \(-6x^2-29xy\) |
| \(7\) | \(x^2+8xy\) |
| \(8\) | \(-xy\) |

由 \(8\mid x\)、\(y\) 为奇数和 (D)，除 \(b=1,5\) 外，各项
\(R_bD_b\) 都属于 \(2\mathbb Z_2\)。具体地：

* \(b=-3,-2,-1,0\) 四项的赋值依次为
  \(3,u+5,u+4,u+5\)。
* \(b=2,3,4\) 三项的赋值依次为 \(1,2,1\)。
* \(b=6,8\) 两项的赋值均为 \(u+1\)。
* \(b=7\) 时 \(D_7=x(x+8y)\) 至少被 \(2^6\) 整除，
  即使 \(v_2(R_7)=-3\)，乘积仍为偶二进整数。

剩下两项各自的赋值为 \(-1\)，必须合并。
对 \(b=1,5\)，只需考虑偏移 \(1\le i\le6\)：
\[
 v_2(4n/i),v_2(12n/i)\ge u\ge2.
\]
因此
\[
 R_1-\tfrac12\in2\mathbb Z_2,\qquad
 R_5-\tfrac16\in2\mathbb Z_2.
\]
又 \(D_1\equiv15\pmod4\)、\(D_5\equiv1\pmod4\)，于是
\[
 R_1D_1+R_5D_5
 \equiv\frac{15}{2}+\frac16
 =\frac{23}{3}\equiv1\pmod{2\mathbb Z_2}.
\]
两项合并后是奇二进整数，且其余十项都是偶二进整数，(C) 得证。

## 3. 控制相邻旧阶，不要求知道它的精确赋值

在旧阶 \(n-1\) 上，令
\[
 L=8n,\quad h=v_2(L)=u+3,\quad m=4n-3,\quad q=n-1.
\]
沿用旧文的
\(r_i=\binom{L+i}{i}^{-1}\)、\(g_k=2a_k/(k+1)\)、
\(G(i)=\sum_{k<i}g_k\)。有限分部求和恒等式为
\[
 2Y(n-1)
 =2\cdot16^{n-1}S_{n-1}+r_mG(m)
  +\sum_{i=1}^{m}\frac{L}{i}r_iG(i-1).
 \tag{E}
\]
设 \(c_i=v_2\binom{L+i}{i}\)。已建立的 Pell 分块公式给出
\(v_2(G(i))=v_2(\lfloor(i+2)/4\rfloor)\)（\(i\ge2\)），
并由此得到每个差项的下界
\[
 v_2\!\left(\frac L i r_iG(i-1)\right)\ge h-2-c_i.
\]
低于第 \(h\) 位不会产生进位，所以
\[
 c_i=v_2\binom{A+\lfloor i/2^h\rfloor}{\lfloor i/2^h\rfloor}.
\]
当 \(1\le i\le m\) 时，高位商恰遍历
\(0,\ldots,(A-1)/2\)，末端商为 \((A-1)/2\)。因此
\[
 \max_{1\le i\le m}c_i=C_A,\qquad c_m=\Gamma_A.
\]
\(q=n-1\) 为奇数，所以 (E) 主项 \(r_mG(m)\) 的赋值为
\(-\Gamma_A\)。BBP 前缀项的赋值为 \(h-2=u+1\)，
其余差项之和的赋值至少为 \(u+1-C_A\)。于是
\[
 v_2(2Y(n-1))\ge\min\{-\Gamma_A,\ u+1-C_A\},
\]
\[
 v_2(16Y(n-1))\ge\min\{3-\Gamma_A,\ u+4-C_A\}.
 \tag{F}
\]
条件 (A) 恰使 (F) 右侧严格大于 \(-\Gamma_A\)。由
\(Y(n)=16Y(n-1)+\Delta_n\) 和 (C)，赋值较小的差项唯一决定
\(v_2(Y(n))=-\Gamma_A\)，证明 (B)。

## 4. 有限核对与未证范围

配套脚本 [verify_bbp_even_dyadic_transfer.py](verify_bbp_even_dyadic_transfer.py) 使用完整 Beta 比值求和与
Pell 递推逐点检查 \(4\le n\le2048\) 的 512 个四的倍数；
它没有使用 12 项差式计算这些 \(Y(n)\) 的余数。
另对 5 个小点用完整既约有理数复算，并对 7 个点逐项核对
\(\Delta_n/H_n\) 的 12 项赋值和合并结果。
运行结果为 473 个点满足 (A)，其余 39 个在充分条件之外；512 个点全都符合
公式 (B)。详见[逐点直接求和的复算记录](bbp-even-dyadic-transfer-verification.json)。

这一有限范围内，连不满足 (A) 的点也都满足 (B)。
这些点在 JSON 中单列为 `observations_outside_hypotheses`；
它们只是更强猜想“所有四的倍数都满足 (B)”的有限证据。
目前的无限结论仍严格限定为 (A)。

另一路[阶乘奇单位与十二项差分扫描](verify_bbp_multiple_four.py)实际检查了
\(4\le n\le32768\) 的 8192 个四的倍数，全部满足
\(v_2(Y(n))=s_2(3n)-2s_2(n)\)。其中 5789 个通过 (A)，2403 个未通过。
扫描用完整 Beta–Pell 求和独立核对了 23 个点，并对其中 12 个小点额外使用精确
有理数核对。扫描记录见[紧凑证书](bbp-multiple-four-verification.json)；脚本可用
`--full-json PATH` 重建全部逐点记录。未通过 (A) 的 2403 个点仍仅是有限证据。

下一条明确待证命题是去掉 (A) 中的进位差条件，证明全部 \(4\mid n\) 上的 (B)。
本轮局部事实 (C) 已对所有这些 \(n\) 成立，剩下的障碍集中在控制
\(16Y(n-1)\) 是否始终比 \(\Delta_n\) 多含至少一个因子 \(2\)。

这项结论仍只控制 \(M=4N\)。它不包含所有偶数，不处理任意
\(M=4N+o(N)\)，也不证明全体有理逼近的坏逼近性质。
