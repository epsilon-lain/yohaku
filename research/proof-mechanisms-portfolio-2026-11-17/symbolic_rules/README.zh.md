# 通用动作组合压缩：一个 4→2 Nielsen 恒等式及其资源限制

本目录只研究固定官方动作的云端符号证明与旧 development 证书。核心结果是在任意有序关系词对 `(U,V)` 上，完整原语串

```text
[4,2,5,2]  →  [2,5]
```

有完全相同的有序自由约简出口 `(UV,U^-1)`，因此可把四步改成两步。它不使用去稳定化、不要求先到 `(x,y)`，也不是旧四步 donor 共轭。它是标准非交换群计算；本目录不主张数学首创。

冻结的 [RULES.json](RULES.json) 包含 11 条具体改写，来自旧 20 例的 17 个原证书片段。这些记录归为 **3 个代数族**，包含上下文扩展和相互重叠的命中，不能当成 11 种独立机制。其中共同共轭搬运与本轮 `conjugation_frames` 组重叠。

## 模型、普遍证明与有限枚举范围

在四生成元自由群 `F(X,Y,U,V)` 中，`X,Y` 是环境字母，`U,V` 是两个独立形式关系词；初态为有序二元组 `(U,V)`。整数编码 `1=X,2=Y,3=U,4=V`，负数表示逆元。只允许官方 rank2 的 14 个动作，共轭字母仅为 `±X,±Y`。

|原语 ID|含义|
|---|---|
|0、1|第 0、1 个关系词取逆|
|2、3|第 0 词右乘第 1 词或其逆|
|4、5|第 1 词右乘第 0 词或其逆|
|6、7、8、9|第 0 词受 `X,X^-1,Y,Y^-1` 共轭|
|10、11、12、13|第 1 词受 `X,X^-1,Y,Y^-1` 共轭|

每个动作后作精确栈自由约简。两个动作串产生完全相同的有序约简输出时，任意固定 `X,Y` 并将 `U,V` 替换为 `F(X,Y)` 中两个任意词的同态，都保持该等式：取逆、乘法、环境字母共轭均与代入相容。这给出普遍端点证明，不是把具体训练状态的巧合当成规则。

[discover_rules.py](discover_rules.py) 穷尽长度 0…3 的 `1+14+196+2744=2955` 个动作串，得到 **1550 个不同的 F4 有序输出**。按最短长度、再按动作列表字典序选规范实现。使用前缀复用只需 2954 次符号动作。完整字典不展开保存；[FINGERPRINT-DIGEST.json](FINGERPRINT-DIGEST.json) 规定其规范序列化并保存 SHA-256：

```text
39533ded37b4a983f63a8353f43a7742ce3095fe87e45bbf50910109ab892e13
```

再扫描旧 20 development 证书中：入口 rank2、每一步仍为 `0…13`、长度不超过 6 的全部连续片段，共 **1440 个片段出现**。逐长度出现数为 `290,270,250,230,210,190`。若其 F4 输出出现在短串表，且规范短串严格更短，就得到候选。相邻逆原语消去和整体恒等输出不作为新候选；本次 11 个不同旧/新串对均不落入这两类。人工逐条核读亦未把已知 donor 四步或直接 D 机制当成新条目。D 不属于扫描字母表。

这里的穷尽性仅针对这个有限 F4 指纹范围。没有搜索长度超过 3 的新实现、长度超过 6 的旧片段、具体状态才成立的特殊恒等式，或全部 AC 路径。

## 核心 4→2 的逐态证明与最短普遍实现

旧四步在自由群中逐态为：

```text
(U,V)
  → (U,VU)
  → (UVU,VU)
  → (UVU,U^-1)
  → (UV,U^-1)
```

第三步的第二槽为 `VU(UVU)^-1 = VUU^-1 V^-1 U^-1 = U^-1`。新两步为：

```text
(U,V) → (UV,V) → (UV,U^-1)
```

其余槽在对应两槽版本中也保持不变，所以同一代数等式适用于任意具有两个不同槽的 rank；本次冻结库保守限制 rank2。具体证书资源仍须逐步检查。

两步是该**普遍变换**的最短原语实现：取 `U=X,V=Y` 时，两槽都改变；每个固定 rank2 原语只改变一个槽，0 或 1 步不能实现。这里没有声称每一种特殊代入都至少需要两步，也没有证明原训练题完整解最短。

## work 不增加，但 peak 能违规

令 `a=|U|, b=|V|, c=|UV|, d=|VU|, e=|UVU|`，长度均在自由约简后计算。旧、新完整局部长度序列分别为：

```text
旧：[a+b, a+d, e+d, e+a, c+a]
新：[a+b, c+b, c+a]
```

包含初态的旧 work 减新 work 等于

\[
2a+2d+2e-c-b=(a+d-b)+(a+e-c)+(d+e)\ge0.
\]

因为 `V=(VU)U^-1`、`UV=(UVU)U^-1`，有 `b≤a+d`、`c≤a+e`。所以这条核心规则的局部 work 普遍不增加，嵌入精确共同端点的完整证书后完整 work 也不增加。

**peak 没有同样保证。** 取 `U=X,V=YX^-1`，旧 peak 为 4，新 peak 为 5。更强的资源反例取 `U=X,V=Y^4999 X^-1`：

|路线|总词长逐态|work|peak|官方结果|
|---|---|---:|---:|---|
|旧 `[4,2,5,2]`|5001、5000、9999、5001、5002|30003|9999|accepted|
|新 `[2,5]`|5001、10001、5002|20004|10001|第0步 `E_LENGTH_LIMIT`|

这是以共同局部出口为目标的合成资源核验，不是到 Stable 空目标的比赛证书。它反驳“步数变少且 work 变少即可无条件替换”。

另将 F2 中长度≤4 的所有 161 个约简词两两组合，穷尽 25921 对输入、每对展开六次原语：**155526 次非官方符号动作**。结果 work 上升 0 对、peak 上升 568 对；结果见 [RESOURCE-EXHAUSTIVE.json](RESOURCE-EXHAUSTIVE.json)，可复现脚本为 [resource_exhaustive.py](resource_exhaustive.py)。有限枚举支持检查，普遍 work 结论来自上面的证明。
