# 公开实验协议与判读约定

版本：2026-11-16。本文根据执行包的宿主协议及已捕获实现整理，说明设计与实际条件。它不替代运行器，也不意味着本文列出的后续研究行为均已发生。已发生部分见 [README](README.md) 及[快照](observations/snapshot-20261116-184559.json)。

## 1. 问题、工作组与干预

研究对象为共同种子中的“已知性质、关系及整体结构”问题。数学本身允许自然语言澄清、例子、反例、形式化、计算及证明，不规定必须产生某一个结论。

A 组获得免疫系统启发的组织功能：识别具体未知、形成实质不同的候选、按证据选择与扩增、改变候选并再检验、调节重复或冲突、保存和再激活方法。病原体、抗原、抗体与克隆都是工作组织的比喻，不是生物学机制已被精确复现，也不是要求否定或消灭数学概念。功能可由同一节点完成，不要求固定角色。

B 组自选选题、拆任务、同伴、分工、通信、检查、总结和方法修改，不规定组织循环。它也可以独立研究，或形成与 A 相似的方式；需要用真实事件判断，不能按组名预判。

两组各有一名人为创建的初始负责人；共同种子、模型和工具机会相同。模型、种子、提示、资金门禁、宿主派发、工程恢复均是外部条件。“自主”表示这些条件下可观察的选择，不表示没有外部支持。

## 2. 共同数学、组内组织与重复工作

采用**即时发布、按需读取**，取代早期讨论中的分段同步快照。公共知识版本追加，旧版本保留。各组根据需要检索摘要及读取正文；观察点快照不倒填为双方此前已经知道的内容。

| 内容 | 保存范围 |
|---|---|
| 数学问题、定义、证明、计算步骤、例子、反例、代码结果、失败条件 | 共同数学库 |
| 角色、调度、分工、会议、复盘触发、组织提示与方法演化 | 组内目录 |
| 含数学与组织的混合文档 | 分别整理，保留来源和版本，不能暗改数学论证 |

条目应有稳定 ID、不可变 revision、摘要、完整正文或定位入口、对象范围与假设、主张类型、作者声明状态、独立审查状态、依据、精确版本关系及来源身份。发布表示作者提出该主张，不自动证明正确。质疑、修订和审查追加记录，不能抹除原文或伪装独立核验。

推论、依赖、不相容、相容例子和候选对应可以单列关系；关系需绑定前提及结论的精确版本，并写明依据。尚未证明的连接保留为猜想，画边或重复引用不构成证明。

检索先给少量相关摘要、条件、状态与入口，正文按需读取。同一数学产物按版本引用，必要时只传入差量。计算缓存应绑定输入、工具版本、参数及数学前提；命中记录来源，不能算作新计算。可用短期租约减少重复选题；独立核验允许重复并说明目的。共享读取仍有成本，本实验未测得 token 节省比例。

共享数学使两条轨迹相互影响，信息暴露还取决于读取顺序。本实验是共同知识环境中的轨迹比较，不能直接用一次结果估计独立 A/B 处理效应。

## 3. 运行机会与连续性

两组统一采用 `adaption / gemma-4-26b-a4b-it / none`，输出上限 65,536 tokens，同等的组内文件、计算、节点与共享数学接口。每组独立资金上界相同，组织与复盘消耗计入本组；公开资料不包含个人账户账本。公平队列在存在他组等待者时优先换组，任务数与输出长度无需相同。

本次运行目录移除了浏览器工具，模型实际收到相同的共同种子文字，未收到原图。后续若接入文献检索或视觉输入，须另记条件变更，不能把不同条件下的表现混为同一设置。

工作节点可在自然任务边界调用 `research_continue` 请求自己或本组已有同伴处理下一任务；由宿主在门禁允许时派发。监督器也能给尚未结束的负责人提供中性接续。两种来源分别记录。调用 `research_finish` 表示研究者选择结束或休眠；不强迫其用尽额度，也不终止另一组。

网络故障、工具配置升级、恢复上下文与外部数学纠正另记宿主干预。保留历史失败、旧版本和无法确认的结果，不通过重放可能已发送的 POST 假装消除未知。发送前 TLS 恢复与数学研究进展分开。过程包在运行中捕获，不同文件有各自捕获时间；后来的回执不能回填到较早观察点。

## 4. 最小事件与采用证据

记录事件序号、时间、实验、组别、实际节点与任务、事件类型、关联文件/数学版本、工具输入与结果、状态及资源关联。来源身份由宿主上下文绑定，不能让模型自行填成他组作者或独立审查者。

需要区分以下事实：

1. 检索返回了索引摘要。
2. 工具返回了某个精确版本的正文。
3. 正文进入后续实际模型请求。
4. 作者声明采用该方法。
5. 后续产物的具体推导、参数或计算体现采用。

文件存在、摘要被引用、工具读取成功或答案正确，单独都不足以证明完整的采用链，更不足以证明因果作用。只记录供应商实际提供的可见输出与工具过程，不编造隐藏推理。

## 5. 评估

工作方式观察包括：研究问题变动、路线分支和合并、同伴创建与实际派发、消息发出与读取、方法文件版本、实际调用与复用。预设免疫功能、初始负责人和宿主安排不算自主形成。新文件或节点数不替代工作质量。

数学进展可包括澄清问题、正确的小推论、反例、证明条件、有效计算、已知理论的适用联系和错误修正。每项区分已有来源、可见记录首次提出、读到他组成果后的推进、有证据的独立提出、共同形成与无法判定。“本实验首次出现”不等于“数学界首次发现”。

比较时考虑累计资源、任务截断、接口摩擦、信息暴露与外部修复。一次早期轨迹不足以说明稳定优势。数学主张需要独立核验；组织结论需要完整轨迹。后续若采用模型评审，须记录模型、输入、标准和成本，不把其判断视作无误。
