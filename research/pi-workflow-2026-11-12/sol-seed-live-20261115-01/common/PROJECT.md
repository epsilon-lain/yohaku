# π 群体研究：起始材料

目标：研究 π 的有理逼近性质。结合已有结果，自行决定值得做的工作，利用可用工具与同伴，并留下可核查的成果和未解决的问题。

已有数学材料在 RUNB-INDEPENDENT.md 与 check_runB_independent.py。读其明确范围。报告中的过程状态属于其注明的历史阶段，不代表今天所有合作状态；本轮只将数学内容与可复现代码作为起始资料。原项目另有关心有限进制表示与有理逼近关系的兴趣，不强制选择该路线。

本轮是新上下文小组，不是原本机负责人接续，也没有发生此前的参数训练。初始条件是两名研究者与一名指定Sol观察者。具体研究路线、分工、检查方法和交流由组内选择。没有要求必须形成某种组织形态，没有要求必须得出新纪录。

可使用 Python 标准库精确计算、写文件及组内消息。研究者分别只修改自己的目录，Sol只修改observer目录；可以读取共同项目目录内彼此产物。不要覆盖基线或同伴文件。没有外部服务调用、其他私人数据访问或新增代理授权；需要的额外资源可记录为请求，不自行扩大。

请使用当前提供的材料与本地工具；不联网。每条具体数学或历史主张保留来源、条件与限制；文件保存不等于数学批准。不要为了迎合观察角色而强制找错。

本轮每个成员最多8次工具编排调用、每个计算任务不超过60秒、累计本地计算不超过120秒；最多一次后续接续工作窗口。模型底层token和请求计费不可见，不据此假定等算力。请记录实际执行的主要命令与结果、发出的消息、收到的消息及如何处理；这些自述需与产物分开保存。
