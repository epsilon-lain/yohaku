# 共享数学知识下的免疫启发与自主组织：首段观察

实验登记：`immune-autonomous-20261116-01`。本目录保存工作流设计、实际起始提示和截至 **2026-11-16 18:45:59（北京时间）**的过程包审查。它是一个早期案例记录；不表示实验已结束，也不提供此后进程是否仍存活的实时结论。

**English abstract.** We compare an immune-inspired organization prompt with an agent-directed organization prompt in Yohaku while sharing mathematical knowledge. A captured early trajectory shows route planning and a self-selected continuation in group A, and document-interface friction followed by a successful source read in group B. No peer organization, new shared mathematical result, or stable performance difference is established. Immediate sharing couples the trajectories, so this is a descriptive case study rather than an independent causal A/B experiment.

## 研究问题与成果边界

数学研究问题是：已确定的性质及其关系，能把一个对象的整体结构约束到什么程度？“白点”表示已经有依据的性质；未知性质不等于不成立。工作流研究问题则是：面对同一开放问题，不同起始组织规则会怎样影响选题、任务、工具、协作与方法记忆？两条研究线分别记录。

本次可交付的成果是明确的实验协议、可定位的早期行为记录，以及对证据边界的审查。另行完成的[性质、候选空间与图论核验笔记](https://github.com/epsilon-lain/lain-s-note/tree/main/research/properties-and-structures-2026-11-16)属于数学研究整理，**不计为这两组已经产生或读取的成果**。

## 实验条件

| 条件 | A：免疫启发 | B：自主组织 |
|---|---|---|
| 起点 | 一位人为创建的负责人 | 一位人为创建的负责人 |
| 组织提示 | 缺口识别、多样候选、证据选择与扩增、变异、调节、记忆 | 自选拆任务、同伴、分工、检查、总结与工作方式 |
| 数学起点 | 相同的共同种子文字 | 相同的共同种子文字 |
| 模型 | `gemma-4-26b-a4b-it / none` | 相同 |
| 工具机会 | 相同的组内文件、计算、节点与共同数学接口 | 相同 |
| 数学知识 | 即时发布、按需读取、精确版本共享 | 同一共享服务 |
| 组织材料 | 保留在本组 | 保留在本组 |

双方输出上限均为 65,536 tokens，模型身份按完整供应商回执中的模型字段核对。首次推理前因 GLM 目录名与计价名不一致，执行方明确选择上述同一模型；没有在本次实验中混用 DeepSeek。原图保存在[种子附件](prompts/seed_diagram.png)，本段运行只给两组相同的文字，未声称模型看过 PNG。

实际运行目录移除了浏览器工具；本事件前缀中未观察到外部文献检索。提示中允许参考已有理论，不等于本次工具配置已提供相应检索能力。这会限制对“文献研究能力”的判断。

数学定义、证明、方法、反例、代码结果与失败边界可以共同使用；角色、调度、提示和组织经验属于各组档案。共享可减少重复构建，但双方读取仍消耗输入 tokens，本文没有测得节省比例。读取时间不同还会造成信息暴露不同，因此不估计两个独立处理组之间的因果效应。
