# 一个有实际证书支持的解释：省掉多余的中间目标

2026-11-17。这是固定实验完成后的解析解释，不是用测试结果调整算法。应用结果中的七次训练证书改善使用同一个机制，均由基线的一原语匹配发现；不能归功于新增的关系词整体共轭宏。

## 观察到的具体片段

七份原证书都到达精确状态 `(y,x)`，即整数编码 `((2,),(1,))`。原后缀为

```
[0,2,5,2,8,16,15]
```

前五步先把 `(y,x)` 变为 `(x,y)`，接着删除第二个关系词，再删除最后一个关系词，得到 Stable AC 的空目标。

同一入口可以直接执行

```
[15,15]
```

第一次删除当前第零槽的关系词 `y`；生成元 `y` 不在其余关系词 `x` 中出现，所以满足官方去稳定化前提。剩余状态恰为 `(x)`，第二次删除后为空。因而从入口开始是 **7→2步**。实际后处理器匹配的是前六步与单步 `[15]` 的精确相同出口，保留最后一步。

这不是免费改名或把同构状态当成相同状态：两条路线都用真实官方动作，且共同出口的有序状态逐字相同。七条完整训练路径均已独立重放，并通过官方训练 manifest 的 CLI 入口验收。计分实例 `sac-07445` 没有出现这一收益，仍为15步。

## 一个简单的精确结论

考虑 rank 为 k、所有关系词恰是当前生成元的一个正置换：每个生成元只在唯一一个单字母关系词中出现。每次都可合法删除任一关系词及其唯一生成元；官方重标号后，剩余状态仍是同类状态。因此 k 次去稳定化即可到空目标。

任何 Stable AC 路线从 rank k 到 rank 0，若有 z 次稳定化与 d 次去稳定化，必有 d-z=k。总动作数至少 d+z=k+2z≥k。因此上述 k 步路线是这一类入口状态到空目标的全局最短路线。在 `(y,x)` 的特例中，最短恰为2。

这项结论只覆盖正置换单字母状态，不能给七个原始训练实例的完整解证明最短，也不涉及一般 AC 的精确有序目标 `(x,y)`。

## 对概念研究的含义

同一对象可以拥有多个有用表示，但求解计划还须按最终目标选择中间结构。在这组证书里，先把关系词排成 `(x,y)` 是一个可以省去的中间目标；Stable AC 只要求最终为空。把当前对象直接理解为“两个已可删除的生成元—关系词对”，就暴露了两步解法。

因此下一步值得研究的是：一个概念翻译是否引入了额外中间目标，以及这些目标能否被带完整证书的直接构造取代。它比单纯给长操作起一个短名字更具体。本轮已经有这个小机制的实际证书；更一般的结构翻译收益仍须另行实验。
