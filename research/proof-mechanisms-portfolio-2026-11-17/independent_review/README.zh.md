# 独立复核：六类机制、完整证书与零新增计分改善

本队解析核读五个方向的规则、证明和最终材料。**通过验收，没有发现遗留的证书或计数错误。** 审查中确认：符号核心规则的 work 不增，但 peak 可越界；共同共轭也必须实际检查资源；DAG 动态规划的保证只在已生成的固定图内成立。所有本轮真实计分路线仍为 `sac-07445` 的15步、work128、peak13。

## 逐项结论与条件

- **accept：符号规则的普遍端点。** 在自由群 `F(X,Y,U,V)` 中的完整有序输出相同，固定环境 `X,Y` 并任意代入关系词 `U,V` 后等式仍成立。冻结库只用固定 rank 的 I/M/C，不把 rank2形式变量误当实际环境生成元。
- **condition：缩步与 work 下降不保证 peak。** 对核心007设 `a=|U|, b=|V|, c=|UV|, d=|VU|, e=|UVU|`，旧 work 减新 work 为 `(a+d−b)+(a+e−c)+(d+e)≥0`。本队独立构造 `U=x,V=x^-1 y x^-1`，旧总词长序列 `[4,3,3,2,3]`，新 `[4,5,3]`；将 `y` 换成 `y^4999`，旧 peak9999、新10001。必须按实际资源筛选。
- **accept / condition：框架不变量。** 共同共轭 `C_h` 与 I/M 相容，执行 `B_h;P;B_g` 可改为 `P;B_reduce(gh)`；v2保持 `U_i=h_i T_i h_i^-1`，仅当乘法两槽的约简 pending 词相同才透传。共轭残余按原语付费展开、rank固定。单槽框架不能随意通过乘法。资源反例的旧长度序列为 `[7504,7502,7500,10000,7500,7502,7504]`，搬框后首次乘法10004，故端点规则不是无条件优化。
- **accept / condition：目标后缀。** 0015入口指数和行向量 `(-1,1),(0,-1)`；0160为 `(1,0),(1,1)`。I只整体变号，C不变指数和；能成为单字母的槽又被另一槽的非零对应指数阻止D。因此在不允许S的该子集中首次D之前必须有M，区别于旧单字母直接删除。没有据此证明完整题最短。goal相对旧baseline两新M机制合计省2步；其整体20例旧baseline295→289是净省6步，包含9例省20步与7例回退14步，不能混写。
- **accept / condition：DAG选择。** 边work不含入口，完整work只加一次初态，peak取max；精确出口保证后缀rank与字母编号相容。三维支配在未来加法/加法/max延伸下安全。所有实际图/标签/转移cap均未触发；最优保证仅指已生成图，不涵盖未入图规则或所有AC路径。图生成候选来源的收益不能归给DP；本轮DP没有额外赢。
- **accept / condition：边界编码。** 右向左原地差分、左向右恢复均正确，`d_0`保留常量偏移信息。输入有符号整数，右边界用二元减法，未隐藏取负；各法共同计n次输入复制和n次最终输出。成本限于数组数值算术；索引、控制和位运算成本边界已明确。全区间族差额 `(n−1)(Q−2)`；n≥2恰Q>2严格省，n=1平。大例200000→2198与不同后缀5050→298通过；单点例200→2398确亏。不是AC成绩或CPU用时证明。
- **error：无遗留项。** 审核途中撤回了可能的peak单调性想法；最终材料已明确反例。复核元数据脚本首次把fragment尝试数误写成5，实际是2次selfcheck加development/freeze/test/report共6次；已纠正，此次失败和重试均官方0，没有重跑应用或调参。
