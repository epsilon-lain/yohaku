# C/I 与 C/I/M 到同一指定删除目标的解析比较

结论：候选严格分离成立。原四步 `[1,4,1,4]` 的正负号正确；另一个排列 `[4,1,4,1]` 同为四步修复，但 work 更低。以 L=12 为主例：C/I 类最短为 **13 步 / work 337 / peak 37**；加入 M 后有到完全相同精确终态的 **5 步 / work 125 / peak 37** 路径。5 步只报上界，不断言 C/I/M 类最短。

本文件只含读源后的解析核对和候选设计，没有运行搜索、官方动作或独立解释器；程序验收由根执行者另报。

## 1. 固定输入、目标和运算类

令整数 L≥1，rank=2，x=生成元1，y=生成元2，槽从0开始。定义

\[
U=x^L,\qquad S=(U,y),\qquad g=U,\qquad
V=C_g(S)=(U,UyU^{-1}).
\]

比较的**实际输入就是 V**，精确目标是删除槽1后的 **rank1 有序 tuple `(x^L,)`**，不是空 tuple，也不是比赛原初态。

- 受限类：逐槽单字母 C 和 I，然后恰执行指定 D₁；此前不许 M、S、其它 D 或免费改名。
- 扩充类：在上述修复中允许 M；下面两条候选始终保留槽0的 donor U，只改槽1，最后执行同一个 D₁。

按固定官方 `sac-r8-v1` 表：

| 编号 | 语义 |
|---:|---|
| 1 | I₁：槽1取逆 |
| 4 | 槽1右乘槽0的正词：v←red(vU) |
| 10 | C₁,ₓ：v←red(xvx⁻¹) |
| 11 | C₁,ₓ⁻¹：v←red(x⁻¹vx) |
| 16 | D₁：槽1必须为一个正生成元，且该生成元不出现在其它槽；删槽并实际重编号 |

每个编号恰为一个原语。M 右乘长度 L 的 donor 仍是官方定义的一个原语；这不是把长度 L 的共同共轭算作免费操作。work 是初态及每个动作后态的**总词长之和**，不是 CPU 运算量。

## 2. C/I 定理的条件和精确后态

在所读 v2 定理中取 r=2、l=1、j=2、z=y、ε=+1，H=⟨x⟩，Z=⟨y⟩。非指定槽只有 U=x^L≠1，所以

\[
m=1,\quad t_H=x^L,\quad b_H=1,\quad
t_Z=1,\quad b_Z=x^L,\quad
\delta_H=0,\quad \delta_Z=L,\quad e=0,\quad N=L.
\]

因此最少修复数为 L，连 D₁ 共 **L+1**。达到路径为 `[11]` 重复 L 次，再接 `[16]`；所有 C 宏已逐字母收费。第 k 次 C 后（0≤k≤L）为

\[
(x^L,x^{L-k}yx^{-(L-k)}).
\]

删除前恰为 `(x^L,y)`。D₁ 删除的是生成元 y=2，实际重编号 ρ₂ 固定 ±1，故删除后恰为 `(x^L,)`。

定理给出的残余 frame 是 ρ₂(t_H)=x^L；其对 U 的作用为
`red(x^L x^L x^-L)=x^L`。所以这里无需恢复动作，且没有把残余框架或编号变化免费忽略。这一恒等式只对本例所选 U、g 作出结论。

## 3. 两条 M 路径

原候选四步 `[1,4,1,4]` 对槽1的逐态计算：

\[
UyU^{-1}\ \xrightarrow{I}\ Uy^{-1}U^{-1}
\ \xrightarrow{M^+}\ Uy^{-1}
\ \xrightarrow{I}\ yU^{-1}
\ \xrightarrow{M^+}\ y.
\]

改进排列 `[4,1,4,1]`：

\[
UyU^{-1}\ \xrightarrow{M^+}\ Uy
\ \xrightarrow{I}\ y^{-1}U^{-1}
\ \xrightarrow{M^+}\ y^{-1}
\ \xrightarrow{I}\ y.
\]

两条都精确实现 v↦U⁻¹vU，M 均使用**正 donor**，无需先把 donor 取逆。槽0全程不变，最后 D₁ 的两个 guard 均满足；完整编号分别是 `[1,4,1,4,16]` 和 `[4,1,4,1,16]`。

## 4. 全部 L≥1 的 length / work / peak

下表的 work 均包含入口一次及最终 rank1 状态，length 包含 D₁。

| 路径 | 逐态总词长（包含初态） | length | work | peak |
|---|---|---:|---:|---:|
| C/I 达界路径 | 3L+1, 3L−1, …, L+1, L | L+1 | 2L²+4L+1 | 3L+1 |
| 原 M 候选 | 3L+1, 3L+1, 2L+1, 2L+1, L+1, L | 5 | 12L+5 | 3L+1 |
| 改进 M 候选 | 3L+1, 2L+1, 2L+1, L+1, L+1, L | 5 | 10L+5 | 3L+1 |

C/I 的 work 来自 `Σ(k=0..L)(3L+1−2k)+L`。本族还可证明它是整个受限 C/I 类的最小 work：单字母 C 每次总长最多下降2，I 不改长度；所有修复态中，槽0的 x 指数和绝对值为 L，槽1的 y 指数和绝对值为1，因此总长至少 L+1。若修复用了 n≥L 步，则前 L 步逐项不小于表中序列，余下每步至少贡献 L+1，故

\[
W\ge 2L^2+4L+1+(n-L)(L+1).
\]

达界路径取等号。二类的最小可能 peak 都至少是输入的 3L+1，两条构造均达到该值。

L>4 时，5<L+1，因此有严格的动作数分离；改进 M 路径的 work 也更小，因为差值为 `2L²−6L−4>0`。L=1,2,3 时所列 C/I 路径更短；L=4 动作数同为5，改进 M 路径 work 为45，小于 C/I 的49。这些比较不声称所列 M 路径在任何参数下最短。

### L=12 的可手核数据

| 路径 | 编号 | 总词长序列 | length / work / peak |
|---|---|---|---|
| C/I | 12个11，再16 | 37,35,33,31,29,27,25,23,21,19,17,15,13,12 | 13 / 337 / 37 |
| 原 M | 1,4,1,4,16 | 37,37,25,25,13,12 | 5 / 149 / 37 |
| 改进 M | 4,1,4,1,16 | 37,25,25,13,13,12 | 5 / 125 / 37 |

建议以改进 M 路径作主例；原候选保留为独立的正确对照。

## 5. 识别、制造、拼接与边界

本例把 g、S 和实际 V 随参数显式给出；本次已解析核对 `V=C_g(S)`。这不提供从任意 tuple 识别共同框架的算法或搜索加速结论。若原任务需要先识别 g/S 或搜索这条候选，该计算资源须另外报告，不能用路径 work 代替。

若已有前缀 P 到达 V，且其 work W_P 已包含 V，则完整路径费用为：动作数 `len(P)+len(R)`，work `W_P+W_R−(3L+1)`，peak `max(peak(P),peak(R))`。入口只能计一次；其它原始前缀、后缀也须保留。

例如从 S 用 `[10]` 重复 L 次制造 V，是一个明确的收费前缀：length=L，work=(L+1)(2L+1)，peak=3L+1；这只是示范前缀，不宣称制造最优。但若实际输入是 S，D₁ 本来已合法，直接删除就是1步、work=2L+1、peak=L+1；不能借故先制造 V 后宣称解决 S 的收益。

L>1 时 `(x^L,)` 呈现循环群 ℤ/Lℤ，本局部目标不能改写成空 tuple 的 Stable 平凡化或比赛成绩。这里唯一证明的类间严格分离是：**给定同一 V，到同一指定 D₁ 后的同一精确 `(x^L,)`，C/I 类所需 L+1 步，而 C/I/M 类存在5步路径。**
