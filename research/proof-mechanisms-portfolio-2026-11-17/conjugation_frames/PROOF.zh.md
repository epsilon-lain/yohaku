# 共同共轭框架的搬运与收费合并

本文只证明已有官方原语的重构恒等式，不主张文献首创、一般 Andrews–Curtis 突破或下述展开的最短性。原语语义来自固定官方 commit `a0fd6e6f52d82c93ccc06ab91d81e8fa3678256e` 的 `core.py`、`stable_core.py`；执行脚本核对旧源锁的全部30个文件，直接 compile 核过 hash 的源码字节。

## 1. 对象与原语

固定当前 rank 为整数 (1\le k\le8)。设 (F_k) 为生成元 (x_1,\ldots,x_k) 上的自由群；字母用非零整数 (\pm1,\ldots,\pm k) 表示。状态是完整有序 tuple (S=(r_0,\ldots,r_{k-1}))，每个 (r_i) 都以唯一自由约简词表示，槽索引从0开始。对 (h\in F_k)，记

\[
\mathcal C_h(S)=(h r_0h^{-1},\ldots,h r_{k-1}h^{-1}),
\]

式中各分量均自由约简。(I_i) 把第 (i) 槽取逆；(R_{ij}^{s}) 把第 (i) 槽右乘第 (j\ne i) 槽的 (s\in\{1,-1\}) 次幂；(C_{i,a}) 是官方单字母共轭 (r_i\leftarrow a r_i a^{-1})。

令 (h=a_1\cdots a_m) 是自由约简词。对每个槽依次执行 (C_{i,a_m},\ldots,C_{i,a_1}) 就实现该槽的 (C_h)。因此同时作用全部 (k) 槽的标准展开长为 **(k|h|)**，没有免费转换或生成元改名。本文给的是上界：某些槽上的共轭可能恰好不改状态，但展开的原语仍真实收费。

## 2. 连续共同框架配对规则 v1

若一个纯共轭块 (B) 中，第 (i) 槽实际依次执行的共轭字母为 (b_{i,1},\ldots,b_{i,n_i})，则该槽的净共轭词为

\[
h_i=\operatorname{red}(b_{i,n_i}\cdots b_{i,1}).
\]

未被修改的槽也须纳入判定，其净词是空词。若所有 (h_i) 作为自由约简词逐字相同，等于 (h)，则 (B) 实现完整状态上的 (\mathcal C_h)。这只是可判定的充分条件，没有通过状态同构或循环词等价放宽。

设 (P) 是同一 rank 上只由 (I_i,R_{ij}^{s}) 构成的有限动作段。共同内自同构保持逆和积，所以

\[
\mathcal C_h\circ I_i=I_i\circ\mathcal C_h,
\qquad
\mathcal C_h\circ R_{ij}^{s}=R_{ij}^{s}\circ\mathcal C_h.
\]

逐动作归纳得到 (\mathcal C_h\circ P=P\circ\mathcal C_h)。若按**执行顺序**写原段为 (B_h;P;B_g)，则对应函数为

\[
\mathcal C_g\circ P\circ\mathcal C_h
=P\circ\mathcal C_{gh}
=\mathcal C_{gh}\circ P.
\]

因此可改为 **(P;\operatorname{compile}(\mathcal C_{\operatorname{red}(gh)}))**。注意合并顺序是 (gh)。若两个原框架分别含 (q_h,q_g) 个实际原语，新展开长为

\[
|P|+k|\operatorname{red}(gh)|,
\]

原段长为 (q_h+|P|+q_g)。框架恰互逆时可去掉两个框架，但这依赖原语恒等式，不能把每个框架当成零费记号。实现只枚举 (P,h,g) 均非空且严格缩步的情况。

## 3. 交错开启与部分关闭规则 v2

v1会漏掉被取逆动作分开的框架开启，以及只关闭部分槽的情形。以下带不变量的规则处理这些情况，并明确何时必须停止。

对一个固定 rank 的候选区间，以原入口为基准初始化两个有序词组 (U=T)，并令每槽待决框架词 (h_i) 都为空。依次扫描原段，维持不变量

\[
U_i=h_iT_ih_i^{-1}\qquad(0\le i<k).
\]

(U) 是执行原段前缀的状态；(T) 是只执行已输出 I/M 原语的状态。三个允许步骤如下。

1. 原动作为 (C_{i,a})：只令 (h_i\leftarrow\operatorname{red}(a h_i))，不输出 I/M 动作。不变量因 (a(h_iT_ih_i^{-1})a^{-1}=(a h_i)T_i(a h_i)^{-1}) 保持。
2. 原动作为 (I_i)：输出同一个 (I_i)，并按原语修改 (T_i)。因为 ((h_iT_ih_i^{-1})^{-1}=h_iT_i^{-1}h_i^{-1})，不变量保持。
3. 原动作为 (R_{ij}^{s})：**仅在自由约简后的待决词 (h_i=h_j) 时**输出同一个 (R_{ij}^{s})。此时

\[
(h_iT_ih_i^{-1})(h_jT_j^sh_j^{-1})
=h_i(T_iT_j^s)h_i^{-1},
\]

故保持不变量。若两词不同，这个区间在该动作处停止，不能直接继续搬运。

扫描结束后，对每槽收费展开 (C_{h_i})，便使 (T) 逐槽成为原出口 (U)。归纳证明覆盖任意合法初态，不依赖实例词内容；唯一自由约简正规形把群元素相等提升为**完整有序自由约简 tuple 精确相等**。新段长度为

\[
\#\{\text{原区间内 I/M 动作}\}+\sum_{i=0}^{k-1}|h_i|.
\]

这允许不同槽保有不同残余框架，但每次乘法的两个参与槽必须共享同一待决框架。v1是其所有槽共同框架的特例。实际 v2 枚举器要求至少一次乘法带着**非空**共同框架通过，并要求严格缩步，以免把单纯的 C/I 相消另计成框架机制。它不合并 I/M 动作、不使用 donor 四步宏，也不做目标直接删除优化。

一个固定可核验的例子是

```
[13,1,9,2,8] -> [1,2,13]
```

按官方编号，先在槽1以 (y^{-1}) 开框，槽1取逆，再在槽0以 (y^{-1}) 开框。到乘法2时，两槽的待决词都为 (y^{-1})，所以可搬过该乘法。最后的槽0共轭 (y) 消掉该槽框架，仅余槽1的 (y^{-1})，必须在新段末尾执行动作13收费还原。这条参数特例由同伴 symbolic_rules 消息明确提示，本组不把它重复计为独立发现。

## 4. 不能删除的条件

**只对一个槽开框，不能普遍搬过乘法。** 在 (S=(x,y)) 上，原段 ([6,2,7]) 产生 ((yx,y))，而只执行 ([2]) 产生 ((xy,y))。v2的两个待决词分别为 (x) 和空词，恰好在乘法处拒绝。两个端点不是精确相同状态。

**中段不能任意含共轭。** 取 (S=(x,y))、(h=x)、中段 (C_{0,y})。原段 (\mathcal C_x;C_{0,y};\mathcal C_{x^{-1}}) 的第0槽为 (x^{-1}yx y^{-1}x)，而直接执行 (C_{0,y}) 得 (yx y^{-1})。一般内自同构不与固定字母的单槽共轭交换。

**稳定化不能无成本穿过并扩展共同框架。** 在 rank2 状态 ((x,y)) 上，先共同 (C_x) 再稳定化，得到 ((x,xyx^{-1},z))；先稳定化再在三个槽共同 (C_x)，得到 ((x,xyx^{-1},xzx^{-1}))。新增槽是否被共轭是实际区别。本文两种生成器遇到稳定化都停止。

**去稳定化还有适用性与重标号。** 在 ((x,y)) 上 D0 合法并产生 ((x))（删除原 (x)，原 (y) 重标号为 (x)）。共同 (C_y) 后成为 ((yxy^{-1},y))，D0因该槽不是正单字母而拒绝。即使另有特殊状态使两边都适用，也须检查被删生成元不再出现、剩余字母映射与槽重排；不能把重标号当成免费精确状态相等。本文不跨 D 搬框。

**缩步和端点恒等式不能替代资源验收。** 取

\[
S=(x^{-1}y^{5000}x,\ x^{-1}y^{2500}x).
\]

原段为全槽 (C_x)、(R_{01}^{+})、(R_{01}^{-})、全槽 (C_{x^{-1}})，共6步，状态总词长依次为

\[
7504,7502,7500,10000,7500,7502,7504.
\]

原段 work 为55012，官方接受。把两框架移除后只有2步，端点仍为原状态，但首次乘法的总词长为10004，官方 `E_LENGTH_LIMIT` 拒绝。两个生成器只生成候选；正式优化还逐步执行全部候选原语，并核完整证书的 length/work/peak。

## 5. 放回完整证明

每条候选都带原区间 ([a,b)) 及展开动作。执行器从精确原状态 (S_a) 用官方 `apply_move` 逐步执行，要求最终与 (S_b) 的 rank、槽顺序、字母编号、符号和完整自由约简词逐字相等。只有这时原后缀才可以原样接回。

完整 work 是包括初态在内的各状态总词长之和，peak是完整路径最大值；候选只替换被删除的区间内后继状态，入口只计一次。执行器对拼好的**整条**路径计算资源，再从原挑战初态运行官方 `verify`；训练挑战还与固定官方训练 manifest 精确核对。没有把“整体共轭等价”或“生成元同构”当作目标验收。
