## 2. 组合乘积界：可交换不代表信息免费

命题A。假设每个S操作与每个T操作交叉交换（只需两库生成元交叉交换）。记r_S=dim W_S、r_T=dim W_T，组合闭包W=W_{<S,T>}、r=dim W，则

max(r_S,r_T) ≤ dim(W_S+W_T) ≤ r ≤ min(n,r_S r_T)。

证明。交叉交换使每个混合词能写成st，s∈S,t∈T。取来自实际行轨道的基ℓs_1,...,ℓs_{r_S}和ℓt_1,...,ℓt_{r_T}。对于任意s,t，先把ℓs展开在前一组基上。再用s_i t=t s_i，把ℓs_i t改写为ℓt s_i；把ℓt展开在后一组基上。故所有ℓst落在r_S r_T个行向量ℓt_j s_i的张成空间，得上界。空词存在，故两单库行空间都包含在W内，得其余不等式。证毕。

注意：这不说两个最小摘要并置就足够，也不要求同一库内部交换。若去掉交叉交换，上界r_S r_T可完全失效：M-e3e7a0b3682b081e@1的交错匹配有r_S=2、r_T=1而组合r=n，n可任意大。因而交换是可核查条件，不是装饰性术语。

## 3. 条件摘要升级的精确额外信息

命题B。设已保留z=M_U x，其中M_U的行为空间U的一组基，U⊆W、u=dim U。另允许在仍可访问原输入时产生任意固定长度消息e(x)，使联合摘要(z,e(x))足以支持全部组合操作。最小消息字母数为q^{r-u}，最小固定长二进制位数恰ceil((r-u)log_2 q)。

证明。固定任一z，仿射纤维M_U^{-1}(z)中，W读出向量有恰q^{r-u}种不同值。可由把U基扩成W基的满秩矩阵直接看出：其余r-u个坐标在此纤维上独立取遍F_q^{r-u}。不同W值可由某个未来词的ℓ读出区分，故在此同一个z下消息必须各不相同。这同时排除非线性消息的更短零误差编码。上界取W基相对U基的补行D，消息Dx；联合矩阵行空间恰W，故可按闭包更新，达到界。证毕。

若U严格小于W且原输入已经删除，只有z的任何确定性后处理均不能升级为组合摘要：取相同z而不同W值的x,y，后处理仍相同，未来某词读出却不同。这是信息不可能，不是尚未找到算法。随机且要求零误差对所有输入也不能创造缺失信息；本文不研究概率容错。

本界只衡量在同一当前对象上增加的信息；不包含消息获取/识别/编码/更新/解码时间。若允许重新读取原输入或外部辅助库，须另记该接口及费用。若对象随后改变，旧消息能否更新须由W闭包证明，不能把一条旧辅助位无限复用给任意新对象。

## 4. 达到乘积界的可交换网格

令a,b≥2，V=F_q^{a×b}，坐标0≤i<a、0≤j<b，ℓx=x_{0,0}。定义

(Ax)_{i,j}=x_{i+1 mod a,j}，
(Bx)_{i,j}=x_{i,j+1 mod b}。

仅允许A或仅允许B反复作用，组合允许任意A/B词；两者显然交换。每次整批循环移位计一个抽象原始操作，最后读取坐标(0,0)免费。没有循环压缩成一门、任意坐标免费读取、隐藏输入分支或额外任意解码器。

W_A由a个坐标读出e_{i,0}张成，r_A=a；W_B由b个e_{0,j}张成，r_B=b。全部ℓA^s B^t=e_{s,t}，故组合r=ab，乘积上界达到。两个局部最小摘要的联合只保留第0行/第0列，秩u=a+b−1；启用两库全部未来能力需要额外

ab−(a+b−1)=(a−1)(b−1)

个域元素的信息，精确位数ceil((a−1)(b−1)log_2 q)。消息可直接取所有内点坐标。这不是额外传一次已有边界，而是具体缺失的信息。

最小手算反例：a=b=q=2，零网格与仅x_{1,1}=1的网格有相同两局部摘要，但AB后的读出分别0和1。各局部摘要可更新，并置后却不能支持全部混合操作。组合4比特、联合局部3比特、升级至少且恰1比特。a=b=3、q=2时对应9/5/4比特。

对预先给定标量目标x_{s,t}，0≤s<a、0≤t<b，固定输入无关词的最少原始操作恰s+t：任何词的A/B次数α,β必须分别同余s mod a、t mod b，故α≥s、β≥t；A^sB^t达到。内点目标在两个单库中均不可表达（坐标函数在全输入域不同），但组合可表达。这里只数移位原语，不把ab坐标物理置换当一条CPU指令，不声称运行时间节省。若整个未来词已知且只需一次终值，直接编码该标量是另一个任务，不推翻在线信息界。
